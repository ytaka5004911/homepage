# Homepage | Search and Useful Tools

A simple, mobile-friendly homepage featuring Google Search, AI Search, URL redirection, and useful web tools.

**Live Website:** https://ytaka5004911.github.io/homepage/

## Features

- **Google Search** — Search the web using Google.
- **Health Consultation Chat** — Access the health consultation chatbot.
- **Offline Support** — Service worker support for offline use where available.
- **Progressive Web App (PWA)** — Includes a web app manifest.
- **Responsive Design** — Works on mobile devices and desktop browser.
- **Dark Mode** — Supports the system's preferred color scheme.

## Technologies

- HTML5
- CSS3
- JavaScript
- Service Worker API
- Web App Manifest
- GitHub Pages

## Getting Started

### Use the Website

Visit the live website:

https://ytaka5004911.github.io/homepage/

### Run Locally

Clone the repository:

```bash
git clone https://github.com/ytaka5004911/homepage.git
```

Open the project directory:

```bash
cd homepage
```

Open `index.html` in your browser. To test service workers and PWA features, use a local HTTP server.
